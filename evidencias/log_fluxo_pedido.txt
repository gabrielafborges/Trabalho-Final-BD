### 1. Cliente 3 escolhe 2 ingressos de Pista do evento 1: reserva temporária de 10 minutos no Redis
redis> SETEX reserva:evento:1:cliente:3 600 "Pista|2"
OK
redis> TTL reserva:evento:1:cliente:3
(integer) 600

### 2. O pedido é gravado de forma permanente no MongoDB (status pendente)
mongosh> printjson(db.pedidos.insertOne({ _id: 14, clienteId: 3, eventoId: 1, dataPedido: new Date(), status: 'pendente', formaPagamento: 'pix', itens: [ { setor: 'Pista', quantidade: 2, valorUnitario: 120 } ], valorTotal: 240 }))
{
  acknowledged: true,
  insertedId: 14
}

### 3. O pedido entra na fila de pagamento do Redis (LPUSH)
redis> LPUSH fila:pedidos:pagamento "pedido:14"
(integer) 1
redis> LRANGE fila:pedidos:pagamento 0 -1
1) "pedido:14"

### 4. O processador de pagamentos retira o pedido mais antigo da fila (RPOP)
redis> RPOP fila:pedidos:pagamento
"pedido:14"

### 6. O Redis reflete a venda: ranking (+2) e resumo rápido (+2)
redis> ZINCRBY ranking:eventos:vendas 2 "evento:1"
"979"
